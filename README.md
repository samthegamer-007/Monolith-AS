# Monolith-AS<br>
**=========================**<br>
**|| MONOLITH ACCOUNTING SYSTEM ||**<br>
**=========================**<br>
A *CLI based* **Accounting software** that I'm building from scratch, <br> Completely using *java* so its **Fast** & **Secure**<br>
-----------------------------------------------------------------------<br>
# **MAS** is still *Under development* so if you wanna try it out, *follow these steps:-*<br>
## 1.Download Monolith-AS.zip<br>
## 2.Extract in a new folder named *"AccountingApp"*.<br>
## 3.Make sure your computer has a suitable **Java Development Kit (JDK)** installed.<br>
## 4.Open the AccountingApp folder with any code editor *(VS Code recommended)*.<br>
## 5.Run **Main.java**<br>
